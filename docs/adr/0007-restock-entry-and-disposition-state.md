# 入库入口与建议处置状态

把补货建议当作唯一入库入口，会让“无建议的实际到货”无法登记，也会把分批到货误判为完成、把建议卡片在未解除风险时隐式移除。我们决定把入库入口从“建议处置唯一”改为三入口：补货建议页、库存总览与耗材档案都可以对目标耗材发起入库，三者复用同一入库单、同一请求标识与同一库存事件契约；建议是协作线索，不是入库前置条件，安全库存线为零或库存充足的启用耗材同样可以登记实际到货。教师与学生直接请求入库仍被拒绝，入库只由班委执行。

补货建议的处置状态改为四态：待跟进（`pending`）、待到货（`awaiting`）、部分到货（`partial`）、风险解除（`resolved`）。状态迁移约束为：待跟进可转待到货或风险解除；待到货可转部分到货、风险解除或回到待跟进；部分到货可继续部分到货或风险解除；风险解除为终态。入库后按当前库存重算缺口：实收数量使缺口归零时置为风险解除；实收小于残余缺口时保留建议并置为部分到货，缺口按最新库存重算；入库纠错使库存重新低于安全库存线时，恢复待跟进或部分到货。卡片只在风险解除或授权角色主动关闭时移除，不由本次入库隐式触发。处置记录保存处理人、状态、关联入库单与更新时间，其他角色可见。

**Considered Options**: 维持“建议处置是唯一入库入口”——无建议收货只能靠直接改库存或伪造建议，分批到货与协作状态无法表达；保留“处置后移除建议卡片”——部分到货会被误判为完成，风险重新出现时无法续接；把部分到货设为可手工选择的状态——与按当前库存重算缺口的规则冲突，未到货也能标记部分到货，故仅由入库结果自动产生。

**Consequences**: ADR-0002 中“建议处置是补货入库的唯一入口”由本 ADR 修订，历史决策保持原样；入库请求必须携带可复用请求标识，重复提交返回原入库单，标识相同但内容不同返回冲突；建议页、总览与档案的入库操作必须落到同一入库单与库存事件；消耗统计与风险总览以当前库存重算的缺口为准，不以建议卡片是否存在为准。
