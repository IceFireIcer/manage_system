# 撤销领用采用红冲而非删除或编辑

> 已被 ADR-0006 修订：[库存事件账本与反向变动族](0006-inventory-event-ledger-and-reversals.md)。

误登记（如数量输错）若允许编辑或物理删除原流水，"库存变动与流水一一对应"的可追溯承诺将被破坏。我们决定：撤销领用生成一条反向数量的红冲流水，原流水标记为"已撤销"但保留；撤销仅教师/班委可操作，撤销原因必填，全部动作写入操作日志。

**Considered Options**: 直接编辑或删除流水——实现最省事但摧毁审计证据链；仅靠后续入库或领用"掩盖"错误——账实长期不符，不可接受。

**Consequences**: 消耗统计必须以"领用与红冲净额"为口径；红冲流水与原流水需双向关联字段；撤销是唯一允许"反向影响库存"的操作。
