# 库存事件账本与反向变动族

库存只减不增、账实不符、来源无法追溯的根因不是页面缺少按钮，而是缺少统一的账本契约。我们决定：任何库存数量变化都必须落为一条不可改写的库存事件，禁止直接改写当前库存。事件类型固定为 `opening`（期初）、`requisition`（领用）、`reversal`（红冲）、`restock`（入库）、`return`（退库）、`scrap`（报损）、`inventory_adjustment`（盘点调整）、`restock_correction`（入库纠错）；每条事件记录变动量、变动前后余额、耗材级单调唯一的执行序号、业务时间与入账时间、来源单据类型与单据 ID、经办人姓名与角色快照、名称/规格/单位快照以及证据状态（`trusted` / `insufficient` / `unverifiable`），并由数据库约束保证 `stock_after = stock_before + delta` 与库存非负。

反向变动不再只有红冲，而是五类并行的反向变动族：

- **纠错红冲**：原领用登记错误，增加库存，上限为原领用数量，计入消耗净额并抵减发出量。
- **实物退库**：学生归还未使用耗材，增加库存，上限为原领用未使用数量，不计入消耗净额，单独列示。
- **报损**：领用后破损无法复用，不增加可用库存，单独记录损耗，上限为原领用数量，不计入消耗净额。
- **盘点调整**：实盘与账面差异，按差异增减库存，以实盘差异为限，单独列示盘盈盘亏。
- **入库纠错**：原入库数量或品种录错，反向冲销库存，上限为原入库数量且不得使库存为负，不计入消耗净额。

五类反向变动共同遵循：保留原记录，记录原因与经办人，关联来源事件或来源单据，同一来源累计反向数量不得超过原始数量；红冲仍保持“一单一红冲”；退库、报损、盘点调整、入库纠错各自生成独立单据与库存事件。

**Considered Options**: 保留“红冲是唯一反向操作”，用撤销领用模拟退库与报损——实物归还未使用耗材与破损报废的数量方向、消耗口径和可用数量都不同，混用会污染净消耗并丢失实物证据；允许管理员直接修改当前库存——账实差异无法归属，审计链断裂；为每类反向操作建独立账本——与领用、入库无法统一对账。均不采用。

**Consequences**: 库存写入必须经事件账本；消耗统计必须区分净消耗与单独列示的退库、报损、盘盈盘亏；历史数据缺执行序号、期初来源或单位时须显式标注证据状态，不得默认一致；查询、导出与接口必须标明使用的是业务时间还是入账时间。ADR-0003 的“红冲是唯一反向库存操作”由本 ADR 扩展取代，历史决策保持原样。
